Architecture

One window, one text response.

VERA samples images from video. InternVL2 sees them together with instructions. The score timeline is built afterward by separate code.

1

Slice the video

The program places an anchor every 16 source frames. Around each anchor it takes a nominal 10-second window, clipped at video edges. At 30 FPS, a full window spans about 300 source frames.

vera_runner/data.py · windows()
2

Select eight images

Eight source frames are spaced across that window. They are images, not eight little video clips. A full window typically samples one moment about every 1.25 seconds. The first sampled moment is at the window start. Exact integer indices come from the code and appear in each result.

vera_runner/data.py · windows()
3

Build one multimodal prompt

The input has eight image placeholders and written instructions. InternVL2 converts each image to visual tokens. Its language model uses those tokens and the text together. It is one batch-chat request for the eight-image sequence. It is not eight independent frame classifications.

vera_runner/backends.py · prompt(), InternVL2.predict()
4

Generate and parse

The model writes an explanation and an “Output: 0” or “Output: 1” field. Code parses that field. The explanation and label come from the same generated text. A malformed output has no valid label.

vera_runner/backends.py · strict_label()
5

Refine the entire video

After every window has a label, VERA combines labels of visually similar windows. It then smooths over time, rounds, expands window scores to frame positions, and applies a whole-video position weight. This requires complete window coverage and aligned visual features.

Original VERA versus this lab

Original VERA generates a text response, parses 0 or 1, then discards the prose when it writes per-window scores. The configurable runner and this lab preserve the raw text and eight input images. Neither original VERA nor this lab supplies verified frame citations for individual sentences.

What the model can inspect

The eight sampled image tensors and the prompt. It sees their order through the image placeholders. The window loader does not pass the omitted source frames, audio, or a dense motion stream.

What this does not prove

An explanation is generated language. It is not a measured attribution. The final timeline may differ from the local label after numerical refinement. A prompt asking for temporal reasoning does not show that the model truly used temporal order.
