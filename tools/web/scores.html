From seven labels to a line.

Switch toy window labels on and off. Watch each numerical stage change. Actual VERA uses many more overlapping windows and external scene features.

Step 1 · VLM judgments

Each selected checkbox stands for a parsed anomaly label of 1. Other windows have label 0.

Initial labels

These came from separate eight-image model calls.

Scene refinement

Labels of visually similar windows receive weights. This toy uses adjacent windows for illustration.

Smoothing and rounding

Nearby refined scores are mixed, then rounded to one decimal place.

Final frame positions

The rounded score is copied across each window’s frame span. A whole-video Gaussian position weight then changes it.

Real implementation: cosine similarity of aligned ImageBind features; top-neighbour aggregation; configured Gaussian smoothing; stride-16 expansion; position weighting centred on the whole video. The final score is a processed anomaly score, not measured frame importance.
