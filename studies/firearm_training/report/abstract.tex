VERA adapts a frozen vision-language model to a video task by letting the model rewrite the guiding questions it answers before it decides. We applied VERA's training procedure unchanged to the VISILAB firearm-action dataset with a frozen InternVL2-8B. The model explains the scene through its answers to the questions, then names the category (Handgun, Machine\_Gun or No\_Gun), the action group and the action code. Training used \val{split_train_videos} videos for 1,200 steps, with selection on \val{split_val_videos} validation videos and a single test run on \val{split_test_videos} videos. The optimizer rewrote the questions in \val{opt_updated} of \val{opt_steps} steps. No learned checkpoint beat the neutral seed questions on validation: the best scored \val{val_selected_category_acc_pct}\,\% category accuracy against \val{val_seed_category_acc_pct}\,\%. On the test split the selected questions reached \val{test_learned_category_acc_pct}\,\% category accuracy against \val{test_seed_category_acc_pct}\,\% for the seed questions. The paired difference was \val{test_learnedminusseed_category_acc_pct} points, with a 95\,\% interval of \val{test_learnedminusseed_category_low_pct} to \val{test_learnedminusseed_category_high_pct}, so no improvement is shown. Action-group and exact-code accuracy did not improve detectably either. The selected questions ask whether a firearm is held and of what kind, and they recognise more handguns, but most handgun videos are still called No\_Gun. The run took about six GPU hours on one RTX~6000 Ada.
