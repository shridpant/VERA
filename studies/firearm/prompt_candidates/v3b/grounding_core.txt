Firearm localization: locate every visible firearm (handguns and long guns such as rifles or machine guns) in each of the eight frames, whether or not the activity is anomalous. Treat all firearms as one class. Give each firearm as a box [x1, y1, x2, y2]: the top-left and bottom-right corners as integers from 0 to 1000, relative to the frame's width and height. Write one line per frame, in frame order, as "FrameK: " followed by a list of boxes, for example "FrameK: [[x1, y1, x2, y2]]" for one firearm or "FrameK: [[x1, y1, x2, y2], [x1, y1, x2, y2]]" for two. Write "FrameK: []" if you see no firearm in that frame and "FrameK: unknown" if you cannot assess that frame.
