\section{Amendment: no new human annotation for proxy feasibility}
This amendment supersedes the reviewer prerequisite below for a limited proxy study; the calibration packet remains preserved. Existing UCA captions and timestamps may define annotation-included versus annotation-excluded inputs, but excluding an interval does not prove visual evidence is absent.

Our reproducible metadata audit found UCA references for 1,412 VERA training and 156 validation videos. Of these, 992 training and 105 validation videos contain both an annotated interval and an unannotated gap at least two seconds long. These are construction-feasibility counts, not sufficient/insufficient truth labels. No new images or predictions were used by the audit.

Before inference, freeze matched-duration/frame-count construction and a measurable proxy endpoint. Report response changes and abstention by annotation condition, not hallucination rates. The 192-call/one-GPU-hour cap remains; no learning run is yet justified. The historical human-review design below is optional for stronger later validation.

\section{Human annotation pilot}
Eight already-consulted UCF sources yield sixteen input views: original eight frames and one frame repeated eight times. Four fixed questions per view concern collision, fire, physical aggression and falling. Neither condition is automatically labelled sufficient or insufficient. All 64 source JPEG hashes were checked. Sheets follow the pinned RGB 448-pixel preprocessing and are blinded to source category and model output. Repetition is visible, so condition blinding is incomplete.

Two reviewers independently complete 64 judgments each. Estimated effort is 43--96 person-minutes plus 20--40 minutes adjudication; these are planning estimates, not measured time. One reviewer supports sanity calibration only. No human labels have been received.
\section{Bounded model pilot, conditional}
After annotation feasibility and narrower novelty review, use separate original-VERA training/development sources, never these consulted calibration videos. Proposed bound: 12 learning and 12 development sources, two views, three prompt conditions; at most 144 evaluation plus 48 optimizer/selection calls, one GPU-hour, one available Ada. All retries count. Keep a separate evaluation set sealed until selection ends. Source/scene checks and actual frame acquisition remain pending.

Compare unchanged VERA, manual selective-explanation prompting and learned questions; include all-abstain and matched-budget controls. Measure unsupported assertions jointly with useful explanation coverage, supported alert retention and over-abstention. Extra human supervision must be disclosed. Stop if manual controls explain gains or labels are unreliable.
