Freeze before inference. Twelve previously consulted UCF test source videos: eight distinct anomaly categories and four normal-video IDs, hash selection without model outcomes. Neither category nor timestamp coverage is a clip-level truth label. No learning, optimizer or prompt selection from these sources. No detection accuracy or semantic faithfulness claims.

Per source: select a UCA annotation≥5seconds and a gap outside the union of all UCA annotations≥5seconds using fixed hashes; take centered five-second windows and eight midpoint-uniform frame samples. Unlike the prior10second windows, these are5seconds, identically for both prompt conditions. Source duration checked against annotations (tolerance max2seconds/2%); source SHA must match frozen03B archive. Sequential OpenCV decode, JPEG95, pinned VERA RGB448preprocessing. This is an annotation-derived proxy, not known sufficient/insufficient evidence. Events can exist in gaps and annotated events may be ambiguous in sampled frames.

Conditions: (A) unchanged original VERA learner instruction/guiding questions and binary output; (B) same guiding questions, model and pixels, with explicit 0/1/2 output (2=insufficient evidence), replacing forced binary decision and 'make necessary assumptions'. Exact effective prompts and hashes saved. Ternary output is a changed task contract, not a drop-in evaluation improvement. Original binary parser cannot parse2; custom strict parser validates each condition without mapping2to1. Upstream parser readings retained as nonauthoritative audit fields.
